      Settings

      Add the folder that contains your genre folders, e.g. /audiobooks. If that folder also holds things you do not want scanned, add the genre folders one by one instead and tick Is a Genre behind each of them.

          A genre is a folder. Creating one makes the folder, and adds it as a library folder when your libraries are single genre folders.

            New audiobooks are picked up from here. Use Import in the left column to file one under a genre and author.

            Who this app writes as, and what each folder lets it do. If it creates folders you are then refused permission to open, that is what this shows: set PUID and PGID on the container to the user that owns the share — 99 and 100 on Unraid — and hand back what was made as root with chown -R 99:100 /mnt/user/Audiobooks.

            A page of its own: the address of your Home Assistant, one long-lived access token from it, and this app writes its own sensors into it and plays books on its media players. Nothing to configure on the Home Assistant side.

            Asks Google about the first books that have no series yet, and reports what came back: the series it names, where that came from — the title, the subtitle, or Google's own series data — and how many requests it took. Use it to see why a book gets no series offered. It spends one to three requests of your daily Google quota per book.

            Opens every file of every book to find what a scan cannot see: a folder that is gone, a truncated download, a share that answers but will not read. This reads your whole collection, so on a large one it takes a long time — minutes, not seconds. Whatever it finds is listed under Broken on disk in the left column.

            Covers are named after the image, so a book that gets new artwork leaves its old file behind. This looks for cover files no book uses any more and moves them to covers/duplicates, overwriting a file of the same name already there.

            Writes album, artist, album artist, genre, year, description, cover art and zero-padded track numbers into every MP3 of every book, using what this app shows. Nothing is written empty: a book with no description or narrator keeps whatever its files already carry.

            This runs on the server, so it keeps going when you close the page, and what is left of it is remembered — stop it and it carries on from the same book, even after a restart.

            Who is listening?

            Where you got to in a book, and which books you have finished, are kept per person. Type your name — the same one as last time if you have listened here on another browser, and this browser will remember it.
