      Add the folder that contains your genre folders, e.g. /audiobooks. If that folder also holds things you do not want scanned, add the genre folders one by one instead and tick Is a Genre behind each of them.

          Set on the container as ADMIN_PASSWORD — the Unraid template has a field for it. With one set, anyone opening the app can browse, play and keep their own place in a book, but only an unlocked browser can scan, import, tag, move or delete.

          A genre is a folder. Creating one makes the folder, and adds it as a library folder when your libraries are single genre folders.

            New audiobooks are picked up from here. Use Import in the left column to file one under a genre and author.

            Covers are named after the image, so a book that gets new artwork leaves its old file behind. This looks for cover files no book uses any more and moves them to covers/duplicates, overwriting a file of the same name already there.

            Writes album, artist, album artist, genre, year, description, cover art and zero-padded track numbers into every MP3 of every book, using what this app shows. It runs over the whole collection, book by book, with a bar at the bottom. Nothing is written empty: a book the app has no description or narrator for keeps whatever its files already carry.
